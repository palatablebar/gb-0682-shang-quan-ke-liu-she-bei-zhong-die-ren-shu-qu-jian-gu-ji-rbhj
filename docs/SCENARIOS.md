# 场景与反例

12小时观测，每小时三处设备、三组两两重叠记录。首小时A120、B110、C90，交集40、30、20，可行联合人数230至250。A100、B80、交集30时联合人数150。A、B、C都100但AB80、AC80、BC0，无可行三方交集，必须隔离。脏样例含缺测、同版冲突、BOM、短行、重复与中文换行。

## 矛盾桶候选修正（脏样例21:00桶）

A=B=C=100，AB=80、AC=80、BC=0：三方交集下界max(0,80+80-100)=60大于上界min(80,80,0)=0，整桶隔离。分别撤下一条交集：撤下AB或AC时保留的交集含0，三方交集被迫为0，联合220；撤下BC时T∈[60,80]，联合∈[200,220]。保守包络为[200,220]，存疑宽度20人。该候选在估界页展示三条替代上下界与被撤下约束（原值/来源行/观测ID），重新核对通过前不进正式日汇，正式日汇缺少该段客流；确认后并入包络值，原始六条观测仍留在隔离与裁决记录中。
